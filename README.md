# Red por Internet (ip netns · parte 2)

Dos LANs privadas (10.10.10.0/24 y 10.10.40.0/24) conectadas a través de dos routers de "Internet" con IPs públicas, usando rutas por defecto, SNAT (MASQUERADE) y DNAT (port forwarding).

- Web explicativa: https://melvinfranco99.github.io/red-internet-sencilla/
- Script: [`2_red_por_internet.sh`](2_red_por_internet.sh) → `sudo bash 2_red_por_internet.sh`
